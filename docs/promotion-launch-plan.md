# Riposte Promotion Launch Plan

Goal: create a focused 30-day launch push for Riposte as an open-source AI agent for Stripe dispute evidence.

## Positioning

Riposte helps Stripe-native SaaS and digital-product founders fight disputes with evidence from their own product data.

Short version:

> Open-source AI agent that builds Stripe dispute evidence packets from Stripe data plus your app usage logs.

Avoid overclaiming. Until we have outcome data, say "fight disputes", "prepare evidence", and "source-backed packets", not "guaranteed wins".

## Core Launch Angles

- Open-source alternative to black-box chargeback tools
- Built for SaaS and digital products, not shipping-label ecommerce
- Uses app activity, usage logs, and product evidence, not only Stripe receipts
- Built on Cloudflare Workers stack
- Designed for auditable, source-backed agent work

## Primary Audiences

- SaaS founders using Stripe
- AI tool founders with subscription disputes
- Digital-product builders with usage/activity data
- Developers interested in open-source agents
- Cloudflare Workers builders

## Where To Launch

High priority:

- Hacker News: `Show HN`
- Product Hunt
- GitHub README / repo launch
- X / LinkedIn founder thread
- Reddit: `r/SaaS`, `r/SideProject`, `r/stripe`, `r/CloudFlare`, `r/opensource`
- Cloudflare community/forum

Secondary:

- Indie Hackers
- BetaList
- AI/open-source directories
- Stripe App Marketplace, once the app path is ready

## 30-Day Shape

### Days -30 to -21: Assets

- Tighten README and repo landing experience
- Record short product demo
- Prepare one synthetic dispute walkthrough
- Write the first technical post
- Create a simple waitlist/demo CTA

### Days -20 to -8: Warmup

- Post build-in-public updates
- Comment in Stripe/SaaS/Cloudflare discussions
- DM 30-50 relevant founders for feedback
- Collect objections and turn them into launch copy

### Days -7 to -1: Queue

- Draft Product Hunt listing
- Draft Hacker News title and first comment
- Prepare Reddit variants per community
- Prepare launch thread
- Prepare direct messages to warm contacts

### Launch Day

- Post Hacker News `Show HN`
- Launch Product Hunt
- Publish X/LinkedIn thread
- Announce GitHub repo
- Post selectively on Reddit
- Reply to every serious comment

### Days +1 to +30: Follow Through

- Turn feedback into GitHub issues
- Ship visible fixes quickly
- Publish technical follow-up posts
- Submit to relevant directories
- Book beta calls with founders who have dispute pain
- Publish a short launch retrospective

## Launch Copy Seeds

HN title:

> Show HN: Riposte, an open-source AI agent for Stripe dispute evidence

One-liner:

> Riposte turns Stripe disputes and app usage logs into source-backed evidence packets for SaaS and digital-product merchants.

Founder post hook:

> Stripe receipts do not prove a SaaS customer received value. Your app database often does.

## Rules

- Do not spam the same post across communities
- Do not ask for upvotes
- Lead with demos, evidence, and implementation details
- Be explicit that it is open source
- Be careful with Stripe claims and dispute outcome promises
